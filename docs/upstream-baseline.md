## 已核实的协议事实

- 服务 UUID：`62750001-d828-918d-fb46-b6c11c675aec`
- 命令/通知 UUID：`62750002-d828-918d-fb46-b6c11c675aec`
- 版本 UUID：`62750003-d828-918d-fb46-b6c11c675aec`
- 默认设备名格式：`NRF_EPD_XXXX`
- 默认设备型号：驱动 `0x07`，UC8179，800×480，黑白红
- 位图：单层 48,000 字节；黑红两层共 96,000 字节
- CRC：初值 `0xFFFF`，反射多项式 `0x8408`；CRC 只覆盖 payload
- 块包：`[0x31][block_id LE16][total_blocks LE16][cfg][payload][crc LE16]`
- 单层最多 512 块；payload 至少 94 字节才能覆盖 800×480
- 固件广告超时：120 秒
- 图片模式下，若配置了唤醒引脚，广告超时后进入深度睡眠；设备可能需要按键/唤醒引脚才会再次广播
- 固件没有启用标准 Battery Service（`0x180F` / `0x2A19`）；电池信息只通过厂商服务通知返回
- 连接后发送 `EPD_CMD_INIT (0x01)`，固件依次通知 `mtu=<n>`、`t=<unix_timestamp>`、`v=<mV>`
- `v=` 是 ADC 读取的 VDD 电压，单位毫伏；固件按 3.3V 满、2.8V 低电、2.7V 关机进行近似映射，不是精确电量百分比
- `v=` 不会仅因建立连接而自动上报；未发送 `0x01` 时不能假定已取得电压
- 电压 `<=2800mV` 时固件进入低电量页并暂停正常自动刷新；`<2700mV` 时显示关机页并进入 `SYSOFF`

## 客户端不得照搬的上游行为

1. 上游网页在 CRC 传输失败后自动退回 `0x30` 无应用级确认传输；本项目禁止静默降级。
2. 上游网页按批次发送并在失败后查询缺块补发；UC8179 的 RAM 写入没有按 block_id 定位，跳块补发可能造成画面顺序错误。本项目采用逐块 ACK、失败后整帧重来。
3. 上游网页的 `Math.max(mtu - 8, 20)` 在极小 GATT 写入长度下可能超出实际包长；本项目先核验有效写入长度，再计算块数。
4. 上游没有“像素已正确显示”的独立回执；刷新完成只能按传输确认、刷新请求和等待窗口分别记状态。
5. 不把电池电压换算值写成“精确百分比”；正式显示使用电压与近似电量格，并以目标板实测校准。
