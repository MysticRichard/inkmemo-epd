# 墨笺 InkMemo PRD v0.3

日期：2026-11-02（Asia/Shanghai）  
状态：已批准，当前有效  
替代关系：完整承接 `PRD 原始交接 v0.2`；v0.3 补充用户后续确认的后台运行、自启、暂停/恢复、WPS 链接入口和三套 UI 视觉基线。两者冲突时以 v0.3 为准。

## 1. 产品定义

墨笺 InkMemo 是运行在 Windows 上的个人墨水屏同步助手。它在本机后台读取一份指定 WPS 共享表格，把待办与进行中事项按截止日期排序，排版为 800×480 黑白红画面，再通过 Windows 蓝牙发送给已有 nRF_EPD 看板。

正式路径不得依赖 WPS 桌面客户端、WPS 本地同步目录、每日手工导出或人工打开网页。

## 2. 用户与核心场景

- 单用户、单维护者、单文档、单工作表、单屏幕。
- 用户在任意设备修改 WPS 表格，Windows PC 在下一轮检查中发现变化并更新屏幕。
- PC 登录后程序自动在后台运行，不弹出常驻窗口；用户可从托盘或设置入口查看状态、暂停/恢复、更换 WPS 链接和手动同步。

## 3. 目标与成功标准

1. WPS 客户端关闭时仍可由本机网络自动读取最新云端数据。
2. 五字段事项不丢失、不错误继承字段、不静默截断。
3. 已批准的三套视觉稿在 800×480 上按数量自动切换。
4. 内容变化才刷新；失败时可区分取数、BLE 和刷新结果。
5. Windows 登录后自动启动，单实例后台运行，用户可暂停和恢复。
6. 真实云端修改能在下一轮成功检查后到达屏幕。

## 4. 范围

### 4.1 首版包含

- WPS 云端只读取数适配器，只实现一种经 P0 验证的正式路径。
- 文档链接、工作表和读取范围配置。
- 五字段解析、自然语言截止日期处理、稳定排序。
- 三套批准版式、天气、公历/星期/农历、看板电池。
- 本机 BLE 连接、逐块 ACK、黑红双平面传输、刷新和结果记录。
- 30 分钟检查、启动检查、变化去重、故障缓存页脚、有限重试。
- Windows 后台静默、登录自启、单实例、暂停/恢复、托盘/设置入口。
- 本机脱敏日志、配置和状态保存。

### 4.2 首版不包含

- 向 WPS 回写、完成按钮、状态列、本地第二份事项编辑器。
- 多人权限、手机 App、云中转、服务器、订阅服务、大模型摘要。
- 自动按颜色或删除线猜完成状态。
- 实时秒级同步、自动唤醒 PC、强制阻止休眠。
- 多文档、多屏幕批量和复杂历史归档。
- 未经真机验证的固件修改、局部刷新优化或续航承诺。

## 5. 内容源与取数

### 5.1 来源边界

- 只读取用户指定的一份 WPS 共享表格、一个工作表和可配置区域。
- 已确认示例表头为 `责任人、对接人、完成时间、事项、产品`。
- 完整 WPS 链接只保存在本机配置，不进入 Git、Obsidian、日志或截图。
- 正式适配器选择必须在 P0 通过关闭 WPS 客户端后的真实云端读取验证。
- 允许首次登录/授权及会话失效后重新登录；正常轮询不得抢焦点或要求人工导出。

### 5.2 解析规则

- 表头按文字映射，允许列顺序变化；缺失任一已确认表头时终止本轮并提示。
- 只在实际合并单元格范围内传播锚点值，例如产品纵向合并；不得把空白姓名、日期等一律向下填充。
- 全空行跳过；有事项但缺少日期或产品的行仍保留并标记字段缺失。
- 只读源数据，不改变原表排序、格式或内容。
- 公式优先读取已缓存结果；无缓存时提示用户回到 WPS 重算保存。
- 读取达到技术上限时明确告警，不能静默把上限当表格结尾。

### 5.3 日期

- `完成时间`按计划截止日期处理，不是实际完成时间。
- 完整日期、Excel 序列日期及依据显式看板年度解析的月日可参与排序。
- 未配置看板年度时不推断无年份日期。
- `11月` 等月份级内容在后续明确规则前保留原文，归入日期待定，不猜具体日。
- `4月前` 等歧义表达不自动猜测。
- 跨日后重新计算逾期、今天和临近视觉，但不回写 WPS。

### 5.4 排序与提醒

1. 已逾期。
2. 今天到期。
3. 未来截止日期由近到远。
4. 日期含糊或未填写。

同日保持源表顺序。默认临近阈值为 3 天，作为可配置建议值。红色、`逾/今` 标签和临近红点遵循已批准 UI。

## 6. 已批准视觉与容量

### 6.1 分档

| 有效事项数 | 版式 |
| --- | --- |
| 1–5 | 宽松 v0.16 |
| 6–12 | 标准 v0.11（11–12 项用标准容量子样式） |
| 13–30 | 紧凑 v0.19 |
| 超过 30 或测量不通过 | 返回 `LAYOUT_OVERFLOW`，保留上张完整画面，不发送删减版 |

分档于 2026-11-05 由用户修订（原 1–11/12–20/21–30 作废）。数量只是起始档；最终还要用完整文本、字体和实际换行测量。某档放不下时才尝试下一档，不按字符数猜容量。

### 6.2 标准 v0.6

- 12 项五列表格：产品、事项、完成时间、责任人、对接人。
- 列宽 `80 / 476 / 76 / 60 / 60px`。
- 产品与事项左对齐；后三列右对齐。
- 事项正文约 18px；右侧辅助信息约 13px。
- 红色承担逾期/今天/临近、星期和天气图标点色。

### 6.3 宽松 v0.15

- 6 项完整单列备忘，项目名位于事项上方。
- 截止日期位于项目名同一层右侧，20px。
- 事项 24px / 行高 28px；人员 14px / 行高 16px。
- 每条最小高度 68px；完整显示“责任人 + 姓名”“对接人 + 姓名”。
- 右侧为完整月历、大日期、农历、天气和右上角电压。

### 6.4 紧凑 v0.13

- 左侧只显示大字事项；右侧上层为序号和项目，下层为日期与人员。
- 人员格式固定为 `责 姓名 接 姓名`，角色与姓名之间必须有空格。
- 24 项：事项 16px，项目 12px，日期/人员 11px。
- 30 项：事项 14px，项目 12px，日期/人员 10px。
- 不裁切事项，不改变全局截止顺序。

### 6.5 视觉锁定

三套批准稿不得在实施中重新设计、替换字体层级、改变对齐或颜色语义。只有以下情况才提出新版并重新审核：

- 真实长文本/姓名导致批准结构无法容纳。
- 真机有效显示区域与 800×480 假设不符。
- 无障碍或物理可读性必须调整。

## 7. 抬头信息

- 公历年月日、星期、农历由 PC 本地生成；时区 `Asia/Shanghai`。
- 天气默认城市按上海出稿、配置可改；使用 Open-Meteo，展示城市、状况、当前温度和当日范围，不做多日预报。
- 天气失败显示 `天气 --`，不阻断事项。
- 看板电池通过连接后发送 `EPD_CMD_INIT (0x01)`，从通知解析 `v=<mV>`；不依赖标准 BLE Battery Service。
- 电池以近似格数和电压显示，不宣称精确百分比；未测得电压时显示 `电量 --`。
- 电压 `<=2800mV` 时暂停自动传图并提示；`<2700mV` 按固件保护处理。

## 8. Windows 后台与用户控制

- 登录 Windows 后自动启动，不显示控制台或常驻主窗口。
- 只允许一个实例；重复启动应唤起已有实例或直接退出。
- 托盘/设置入口至少提供：立即同步、强制重发、查看预览、修改 WPS 链接、暂停/恢复、自启开关、查看状态、退出。
- 暂停期间不取数、不连接、不传图；恢复后只补一次最新检查。
- 更换 WPS 链接后保存到本机配置，首次使用新链接时允许重新授权。
- 自启与暂停状态必须持久化，重启后保持。

## 9. BLE 与刷新

- 服务和特征 UUID 以 `docs/upstream-baseline.md` 固定基线为准。
- 使用 `0x31` 顺序分块、逐块应用 ACK、CRC 校验和完整帧提交。
- 禁止在失败后静默降级到无应用级确认的 `0x30`。
- 不按 block_id 跳块补发；任何 CRC、ACK、断连或状态异常都从头完整重传。
- 黑层和红层分别完整传完，全部确认后才发送 `REFRESH (0x05)`。
- 即使无红色内容也发送完整无红平面，清掉旧红色残留。
- 区分“数据确认”“已请求刷新”“等待结束”“用户目视验证”。
- 在测得上游广播和重连行为前，不承诺无人值守半小时必达。

## 10. 调度、去重与失败

- 程序启动后立即检查一次，之后按 1800 秒周期检查。
- 单设备只运行一轮；手动与定时请求合并，不堆积队列。
- 内容、排序、跨日提醒或失败提示变化才刷新；纯读取时间变化不刷新。
- 启动、休眠恢复、重新绑定或固件升级后执行受限设备健康核验。
- 云读取失败且 BLE 可用：发送最近有效事项，页脚显示失败提示并保留旧数据时间。
- BLE 失败：屏幕保持原画面，只在 PC 提示。
- 有效空表显示“暂无待办”；读取错误不能当空表。
- 容量超限不发送删减版，保留上次完整画面并报告。
- 重试必须有总时间和总次数预算，避免多级重试相乘。

## 11. 隐私、安全与数据

- 事项正文、真实姓名、产品、完整链接、Cookie、Token、会话和含原文截图均为敏感数据。
- 默认日志只记录数量、阶段、耗时、错误类型、哈希短值和状态，不记录事项全文。
- 凭证使用 Windows Credential Manager/DPAPI 或项目专用受保护会话；不写入 JSON。
- 预览和原始快照保存在当前 Windows 用户目录，不进入 Git 或 Obsidian。
- 诊断导出默认排除原文、凭证、预览和完整链接。

## 12. 验收门槛

### 视觉

- 三套批准 PNG 与静态源稿归档完整，静态源重渲染一致。
- 实机工程必须复用批准布局，不以源码/DOM 代替截图或真机验收。

### P0

- 关闭 WPS 客户端后，另一设备修改可被后台读取。
- 目标屏幕可发现、可连接；记录固件、MTU、方向和唤醒事实。

### P1

- 虚构 `.xlsx` → 标准任务 → 800×480 预览 → 黑红双平面。
- 校准图方向、颜色正确；失败传图不触发刷新。

### P2

- 后台运行、单实例、暂停/恢复、自启、失败缓存、跨日重算和有限重试通过。

### P3

- 真实云端修改 → 后台取数 → BLE 传输 → 屏幕更新，全程无人工导出或打开 WPS。

### P4

- 五字段完整可读，东西/南北方向与三色正确，实际容量和观看距离经用户真机验收。
- 托盘、链接入口、自启、打包与使用说明可用。

### P5

- 24/72 小时运行、断网、休眠、重启、低电量与真实半小时多轮测试通过。

## 13. 当前待验证事项

- 目标屏上电与持续广播能力。
- 目标固件版本、MTU、驱动、唤醒引脚和刷新时间。
- WPS 桌面客户端关闭后的长时间会话稳定性。
- 文档年度与月份级日期的最终业务解释。
- 真实长文本、长姓名和 30 项可读容量。
- 默认天气城市最终值。
