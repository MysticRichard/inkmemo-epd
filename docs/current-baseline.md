## 已批准 UI

- 标准 v0.6：12 项五列台账；产品、事项左对齐，完成时间、责任人、对接人右对齐。v0.11 仅将逾期标记改为时间左侧的红色实心圆+白色感叹号，结构、列宽与字号不变。
- 宽松 v0.16：1–5 项使用；左侧项目/事项与右侧时间/责任人/对接人三槽等高，右侧保留月历、天气和右上角电池。
- 紧凑 v0.19：13–30 项使用；每半屏为项目日期、事项、人员三列；运行时为 v0.19 三列左对齐实现。
- 数量分档（2026-11-05 用户修订）：1–5 宽松、6–12 标准、13–30 紧凑。6–10 项使用全尺寸标准 v0.11；11–12 项使用标准容量子样式（事项 22px、行高 30px、完成时间 22px、产品/责任人/对接人 15px）。
- 三色：黑、白、红；红色状态色 `#cf1b1b`；分辨率 800×480。
- 视觉批准不等于真实长文本容量、实际物理尺寸或真机可读性通过。

## 不可回退的产品边界

- WPS 桌面客户端未启动、文档未手动打开时，后台仍须读取指定共享表格。
- 只读取一个文档、一个工作表和可配置的 `A:E` 区域；五字段完整展示。
- 排序为逾期、今天、未来由近到远、日期待定；同日保持源表顺序。
- 不新增状态列、不猜完成状态、不建立第二份本地事项清单。
- 不默认分页、截断、隐藏或只显示前 N 条；容量超限时明确报错，不发送删减版。
- Windows 后台静默运行、登录后自启、单实例、可暂停/恢复、可更换 WPS 链接。
- 云端读取失败、BLE 失败、刷新结果不确定必须分别建模。
- 事项原文、真实姓名、完整 WPS 链接、登录会话、Cookie、Token 和截图不得进入 Git 或 Obsidian。
