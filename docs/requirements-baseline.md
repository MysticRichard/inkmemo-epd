## 本轮新增约束

1. Windows 程序必须后台静默运行，不弹出常驻窗口。
2. 登录 Windows 后自动启动；只运行一个实例。
3. 用户可暂停/恢复自动同步，暂停期间不取数、不传图。
4. 提供更换 WPS 文档链接的入口；链接只保存在本机，不进入 Git 或 Obsidian。
5. 墨水屏文字排版必须先通过用户视觉批准，再开始应用代码构建。
6. 看板抬头必须显示当前公历年月日、星期和农历日期；日历信息由 PC 端本地生成。
7. 抬头显示简洁天气：城市、天气状况、当前温度、当日最低/最高温度；默认使用 Open-Meteo，城市可配置。
8. 抬头显示墨水屏电池信息：连接后通过 BLE 初始化通知读取电压，以近似电量图标和电压展示，不宣称精确百分比。
9. 天气或电池读取失败不得阻断事项展示；缺省显示 `天气 --` 或 `电量 --`。
10. 上述抬头信息只占紧凑信息带，不挤压五字段事项表，也不扩大为独立卡片区域。

## 仍需用户确认

- 看板年度：当前日期为 2026 年，但文档中的 `3.18前` 等无年份日期必须在配置年度后才能排序。
- 月份级日期（如 `11月`）是否继续按原文档保留原文、放在“日期待定”组，不推断为具体日。
- 目标墨水屏设备 `NRF_EPD_XXXX` 当前未出现在 BLE 扫描中；实机验证前需要设备处于可发现状态。
- 天气默认城市暂按上海出稿；如实际城市不同，在配置中修改即可。
