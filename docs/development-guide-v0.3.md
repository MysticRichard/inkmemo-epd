# 墨笺 InkMemo 开发指南 v0.3

日期：2026-11-02（Asia/Shanghai）  
状态：已批准，作为当前实现与验收指南  
上游协议基线：`YCD12/nRF_EPD@e86495e25fe69de1c7174b5913aa294c2103242e`

## 1. 技术目标

构建一个 Windows x64 后台程序，把已批准的五字段 WPS 事项通过本机网络与本机 BLE 转换成 800×480 黑白红画面，并可长期无人值守运行。

首版优先正确性和可诊断性，不先追求批量传输、局部刷新或跨平台。

## 2. 建议技术栈

| 领域 | 首选 |
| --- | --- |
| 语言 | Python 3.12 x64，开发时锁定补丁版本 |
| BLE | Bleak，Windows WinRT 后端 |
| 图像 | Pillow + 可再分发中文字体 |
| 表格 | openpyxl，只读 `.xlsx` |
| 云端 | P0 二选一：官方接口或项目专用浏览器会话 |
| 托盘 | pystray 或等价 Windows 托盘库 + 小型配置窗口 |
| 状态 | JSON + 原子替换 |
| 凭证 | Windows Credential Manager 或 DPAPI |
| 分发 | PyInstaller，先目录版再评估单文件 |

不引入 Electron、Docker、n8n、Dify、大模型服务或额外云服务器。

## 3. 模块边界

```text
src/inkmemo/
  sources/       WPS 适配器，只输出来源快照
  domain/        任务模型、日期、排序、哈希
  render/        三套已批准布局、字体、位平面
  ble/           UUID、CRC、逐块 ACK、连接和刷新
  sync/          调度、互斥、去重、重试、状态提交
  windows/       单实例、自启、托盘、暂停/恢复
  storage/       配置、状态、凭证、日志
```

禁止把 WPS 登录逻辑写进 BLE 层，禁止把业务文案硬编码进驱动，禁止让渲染模块自行删减事项。

## 4. 数据模型

单条事项至少包含：

- `task_id`
- `product`
- `content`
- `due_text`
- `due_date`（可空）
- `due_kind`：overdue/today/upcoming/undated
- `owner`
- `counterpart`
- `source_row`
- `missing_fields`

快照至少包含：

- `source_id`
- `source_kind`
- `document_title`
- `sheet_name`
- `fetched_at`
- `upstream_modified_at`（若可信）
- `raw_hash`
- `tasks`

## 5. WPS 适配器

### 5.1 P0 选择

先核查官方接口能否在零新增服务器、零新增订阅和最小权限条件下本地运行；不满足则验证项目专用浏览器会话自动导出/读取。只实现一种正式路径。

### 5.2 正式路径要求

- 不启动 WPS 桌面客户端。
- 首次登录可交互，日常轮询后台执行且不抢焦点。
- 自动产物必须绑定本轮请求、目标文档和工作表，防止读取旧下载。
- 不得用截图 OCR 作为首版主路径。
- 不得读取其他浏览器 profile 的私有 Cookie，不绕过验证码或权限。
- 会话失效停止自动重试并通知用户，不做无限登录循环。

### 5.3 测试

- 无年份日期：年度未配置时不排序、不猜。
- `11月`：保持原文，进入日期待定。
- 产品合并单元格只传播合并区域。
- 空白分隔行跳过。
- 缺人员/日期的事项保留并标记。
- 删除一条、删除最后一条、登录页、403、429、断网和空表分别测试。

## 6. 渲染

### 6.1 资源

- 画布固定 800×480，1-bit 黑层和 1-bit 红层。
- 三套批准稿源与 PNG 在 `design/approved/`。
- 正式实现必须从同一布局参数生成，不把 PNG 当动态模板缩放到任意内容。
- 字体正式分发前核对许可；当前样例使用 Noto Sans SC。

### 6.2 选择流程

1. 完整解析和排序所有事项。
2. 按数量选择起始档：1–5 宽松、6–12 标准、13–30 紧凑（2026-11-05 用户修订）。
3. 用完整文本和最终字体测量宽度、换行、字形高度和页脚边界。
4. 该档失败才试下一档；紧凑先试 24 项字号，再试 30 项字号。
5. 全部失败返回 `LAYOUT_OVERFLOW`，不发送删减版。

### 6.3 固定视觉约束

- 标准 v0.6 列宽 `80/476/76/60/60`，产品/事项左对齐，后三列右对齐。
- 宽松 v0.15 日期 20px，事项 24/28px，人员 14/16px，每条至少 68px。
- 紧凑 v0.15 人员列为责任人/对接人上下排列，角色与姓名保留间距；v0.13 仅保留历史结构。
- 红色只用于状态、星期点色、天气图标和低电量告警。
- 天气、电池失败使用 `--`，不挤掉事项。

## 7. 位图与 BLE

### 7.1 位图

- 每平面 48,000 字节；黑红共 96,000 字节。
- 每行 100 字节，从上到下、从左到右，初始位序高位在前。
- 白底、黑层、红层的极性由非对称校准图确认。
- 不发送 PNG/JPEG 原文件。

### 7.2 传输

- 服务/命令/版本 UUID 按上游基线。
- `0x31` 包：`[cmd][block_id LE16][total LE16][cfg][payload][crc LE16]`。
- CRC 只覆盖 payload；初值 `0xFFFF`，多项式 `0x8408`，无最终异或。
- 每块等待匹配 `0xA0` ACK 后再发下一块。
- 失败即断开旧连接、清空等待器、重新连接并从该层起点完整重传。
- 两层完整后发送 `0x05` 刷新；不得在 GATT write 返回瞬间认定显示成功。
- 禁止自动降级到 `0x30`。

### 7.3 包长

`payload_size = min(gatt_value_limit - 8, 248)`  
`blocks = ceil(48000 / payload_size)`

块数超过 512 时拒绝 CRC 模式。实际 `gatt_value_limit` 由特征和 MTU 实测，不直接使用网页默认值。

## 8. Windows 后台

### 8.1 静默与单实例

- 打包为无控制台窗口的 `InkMemo.exe` 或 `pythonw` 入口。
- 使用命名互斥量/单实例锁；重复启动唤起设置入口后退出。
- 正常运行不显示主窗口，仅托盘图标和气泡/通知。

### 8.2 自启

- 默认随当前用户登录启动，不做系统服务。
- 可通过托盘设置关闭/开启；卸载或用户选择退出时移除自启项。
- 自启状态与程序暂停状态分开保存。

### 8.3 暂停/恢复

- 暂停后调度器不取数、不连接、不传图。
- 恢复后只补一次最新检查，不重放暂停期间全部周期。
- 暂停状态重启后保持。

### 8.4 WPS 链接入口

- 设置窗口提供链接输入、保存、测试连接和重新授权。
- 链接只保存到本机受保护配置，日志显示时脱敏。
- 修改链接后清空旧源快照关联，重新验证工作表、范围和表头，不沿用旧文档缓存。

## 9. 调度与状态

建议状态字段：

- `last_check_at`
- `last_source_success_at`
- `last_transfer_confirmed_at`
- `last_refresh_assumed_at`
- `last_sent_content_hash`
- `last_sent_frame_hash`
- `source_health`
- `ble_health`
- `display_health`
- `last_error_class`

启动后立即检查，之后 1800 秒一轮。内容/排序/临近状态/失败提示变化才刷新。强制重发可绕过去重。

失败退避建议：连接失败 30 秒、2 分钟、5 分钟各一次；CRC/ACK 失败整帧最多两次；刷新不确定先等待保护窗口。所有重试共享单轮总预算。

## 10. 安全与隐私

- 真实 WPS 链接、文档内容、姓名和凭证不进入 Git、公开文档、日志或诊断包。
- 配置原子写入并保留上一版本。
- 凭证使用系统安全存储，不写入普通 JSON。
- 预览文件位于 `%LOCALAPPDATA%/InkMemo/`，不随诊断导出。
- 代码评审和测试夹具全部使用虚构事项。

## 11. 测试策略

### 单元

- 表头映射、合并格、空白行、缺失字段。
- 日期分类、年度、月份级原文、跨日排序。
- CRC 固定向量；包长和 512 块边界。
- 三个布局档的字号、换行、溢出和去重哈希。

### 集成

- 虚构 `.xlsx` 到任务模型和两张位平面。
- 模拟 ACK 延迟、丢 ACK、NACK、断连、黑层成功红层失败。
- 状态保存中断、程序崩溃和重启恢复。
- 暂停/恢复、单实例和自启开关。

### 真机

- 校准图确认方向、颜色和中文。
- 关闭 WPS 客户端后真实云端修改。
- 30 分钟真实间隔多轮、锁屏一小时、休眠恢复、断网、蓝牙关闭、低电量。
- 刷新后设备回日历、重复启动、旧 ACK 迟到。

## 14. 已知风险

- 目标屏不持续广播或深度睡眠，导致无人值守失败。
- WPS 官方接口门槛过高，浏览器会话不稳定。
- 目标板电压经过分压/稳压，`v=` 不能直接当真实电池百分比。
- 三色全刷与 96,000 字节传输耗时较长。
- 真实长文本会使批准样例容量下降。
- 目标固件与上游基线不一致。
