## 设计目标

- 五类字段全部保留：产品、事项、完成时间、责任人、对接人。
- 按截止日排序：逾期 → 今天 → 未来 → 日期待定。
- 不隐藏、不截断、不分页；容量不足时由 PC 端报告，不向屏幕发送删减版。
- 标准稿正文 18px；宽松/紧凑须先按实尺寸审核可读性，不能用电脑放大图或无限缩字替代。
- 红色承担按期状态、当前星期、天气图标点色和低电量告警；白色保持底色，黑色承担正文与结构。
- 抬头用一条紧凑信息带承载标题、事项数、公历/星期/农历、天气和电量，不另做卡片。
- 版式参考见 `docs/design-research.md`；只借鉴信息层级和表格节奏，不复制他人视觉资产。

## 已批准标准版 v0.6

1. 抬头改为三栏信息带：左侧标题与事项数，中间公历/星期/农历，右侧天气与电量。
2. 日期使用大号等宽数字，农历放在第二层；不再让日期与标题争抢同一视觉层级。
3. 天气压缩为“城市、状况、当前温度、当日范围”，不增加多日预报。
4. 电量用 4 格图标加电压，不显示精确百分比；3.18V 显示为约四分之三电量。
5. 事项表使用点线分隔、无竖网格；紧急程度由左侧红条、日期颜色和“逾/今”标签承担。
6. A 保留五列台账；B 保留日期轨道，作为“日程阅读”备选。
7. A 的产品、事项两列左对齐；完成时间、责任人、对接人三列右对齐。
8. 天气图标按 Meteocons / Yr-icons 的厚轮廓思路重绘：八向短射线、红色实心太阳芯、黑色外圈；不直接使用第三方图形。
9. 当前星期和天气图标使用红色点色，完成时间列保留“逾/今/临近点”标记并让日期数字右边缘对齐。
10. 列宽由 `80 / 404 / 94 / 86 / 88` 调整为 `80 / 476 / 76 / 60 / 60`，事项列增加 72px；右侧三列在不截断现有内容的前提下收紧。

## 状态稿

- 正常：12 条虚构事项，日期、天气、电量均正常。
- 有效空表：显示“暂无待办”，保留成功读取时间。
- 云端读取失败：保留缓存事项，页脚显示红色失败提示；不伪装成最新数据。
- 天气/电量不可用：分别显示 `天气 --` 和 `电量 --`，事项照常展示。
- 低电量：电量图标和电压转红，显示 `低电 2.84V`；不显示精确百分比。

## 批准方式

标准 v0.6、宽松 v0.16、紧凑 v0.15 均已获用户视觉批准，不重复询问。应用代码已按批准基线实现；标准 v0.10 和宽松 v0.15 仅保留历史。现行分档为 1–11 项宽松、12–20 项标准、21–30 项紧凑；12 项直接使用标准稿。请使用 `design/mockups/capacity-review-v0.8.html` 的标尺或 100% 打印判断实际大小。静态视觉批准不等于真实容量或真机可读性通过。

同时请确认：

1. 看板年度是否按 `2026` 解释无年份日期。
2. `11月` 等月份级日期是否保持原文并归入“日期待定”。
3. 天气城市是否就是上海。
