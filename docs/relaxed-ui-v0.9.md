# 宽松版 UI v0.9

日期：2026-11-02。状态：待用户视觉审核；仅静态设计，不是应用构建。

后续状态：用户认可本稿整体排版，要求电池移至右上角。当前修订以 `relaxed-ui-v0.10.md` 为准，本文件保留历史依据。

## 修订依据

用户明确指出宽松版无须双栏便笺，右侧空间用于天气或日历。本稿取代宽松 v0.8 双栏方向；标准 v0.6 已批准，紧凑 v0.8 仍待审，本轮均不改设计。

使用 impeccable 的布局与字体层级指导，保留黑白红、现有中文字体和太阳图标。左侧单列依次显示事项，右侧集中显示年月日、星期、农历、月历、天气和电压。红色用于事项日期状态、月历周末与当天定位。所有内容均为虚构演示，不连接 WPS 或设备。

## 布局与字号

画布 800×480。左侧事项区宽 534px，右侧日历区宽 198px（含分隔线与内边距）。事项正文独占一行区域，产品、日期、责任人和对接人在下一层；仍按截止时间自上向下排列。

| 宽松档内数量 | 正文 / 辅助字号 | 条目最小高度 | 说明 |
| --- | --- | --- | --- |
| 1–6 | 24 / 14px | 60px | 放大正文并增加留白 |
| 7–8 | 22 / 13px | 48px | 过渡密度 |
| 9–12 | 20 / 12px | 35px | 单列完整保留五字段，抬头只显示标题与数量 |

这是同一宽松档的静态稿排法，不改变 1–12 宽松、13–20 标准、21–30 紧凑的数量分档。字体与阈值均待视觉审核；实际长文本仍须测量，不能按数量保证容量。

右侧日期日号 78px、年月 17px、星期 16px、农历 13px；月历日期 14px。天气图标 60px、温度 34px、天气说明 13px，电池状态 12px。月历只辅助查看当月日期，不承担任务分配，不隐藏任何事项。
