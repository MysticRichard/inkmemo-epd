## MVP 范围

### 必须完成

1. 项目运行时、依赖锁定、可复现运行入口。
2. 一种真实的 WPS 云端读取适配器。
3. 五字段解析、日期分类、稳定排序、三种容量档位。
4. 三套已批准 UI 的动态渲染、天气、农历、电压。
5. 黑红双平面生成、CRC、逐块 ACK、完整帧刷新。
6. Windows 后台静默、单实例、登录自启、暂停/恢复、链接入口。
7. 30 分钟检查、内容去重、失败缓存、有限重试。
8. 真实端到端验收、用户操作说明和限制清单。

### MVP 后

- 24/72 小时长期稳定性与更细的续航优化。
- 安装包美化、自动升级、代码签名。
- 多文档、多屏、多人协作、历史归档。
- 局部刷新、固件改造和额外硬件网关。
- 自定义字体、主题或用户可编辑版式。

## 分阶段交付

| 阶段 | MVP 增量 | 完成证据 |
| --- | --- | --- |
| P0 | 云端读取与 BLE 可见性 | 关闭 WPS 后真实读取；目标屏可发现并记录能力 |
| P1 | 本地任务到屏幕 | 虚构数据渲染、校准图、一次真实完整帧显示 |
| P2 | Windows 后台运行 | 单实例、自启、暂停/恢复、30 分钟调度、状态恢复 |
| P3 | WPS 真实闭环 | 另一设备修改后自动到屏，全程无人工导出 |
| P4 | 最小可用交付 | 三套版式、链接入口、故障提示、打包、用户验收 |

## 真实端到端验收

MVP 最终演示必须一次连续覆盖：

1. 关闭 WPS 桌面客户端。
2. 在另一设备修改 WPS 表格中的事项。
3. Windows 后台在计划周期内成功读取新版本。
4. 程序按有效事项数选择批准版式并生成正确图像。
5. 本机 BLE 连接目标屏，完成黑红两层并刷新。
6. 用户目视确认字段、顺序、颜色、方向、日期和抬头正确。
7. 再次同步相同内容时不重复刷新。
8. 暂停后不取数、不连接；恢复后只补一次最新检查。
9. 重启 Windows 登录后程序自动运行且只有一个实例。
10. 更换 WPS 链接后能重新验证并读取新文档。

## 停止与报告规则

- 不因单个阶段完成而停止整个目标。
- 遇到登录、设备上电、物理确认等外部阻塞时，先完成所有不依赖该操作的工作，再给出单一、具体的协助请求。
- 不以“代码已完成”“测试通过”代替用户实际屏幕验收。
- 不把视觉批准扩大解释为容量、真机或 MVP 验收。
- 每次关键进展更新 `docs/current-baseline.md` 与相应验证记录。
- 每次交付按“任务、变更、验证、未验证、风险、下一步”汇报。

## 完成判定

只有以下同时成立，才可把 goal 标记完成：

- 真实 WPS 云端到真实目标屏幕的闭环通过。
- Windows 后台、自启、单实例、暂停/恢复和链接更换通过。
- 三套批准 UI 在真实项目中复用，无重新设计。
- 至少一次云端失败缓存提示和一次蓝牙失败路径经过真实验证。
- 用户明确确认实际屏幕显示和使用方式可接受。
- 证据和限制已写回项目文档。
