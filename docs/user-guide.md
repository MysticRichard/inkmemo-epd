# 墨笺 InkMemo 使用说明

## 启动方式

- 开发环境：`.\.venv\Scripts\python.exe -m inkmemo run`
- 目录版：`dist\InkMemo\InkMemo.exe`
- 程序无主窗口，启动后常驻 Windows 托盘；已开启自启时，登录后自动运行。

## 首次配置

1. 打开托盘菜单的“设置 / 更换 WPS 链接”。
2. 填写 WPS 共享表格链接并设置看板年度；天气按设置里填写的城市查询，城市留空时才使用 Windows 本机定位。
3. 点击“保存并测试连接”；云端读取成功后，“查看预览”可看到本机画面。
4. 如果页面要求登录或权限确认，点击“WPS 授权”，在弹出的 Edge 窗口完成操作后关闭窗口。
5. 需要随 Windows 登录启动时勾选“登录 Windows 后自动启动”。

链接、Cookie 和会话不会写入仓库；WPS 链接使用 Windows DPAPI 保存，浏览器会话保存在当前 Windows 用户的本地应用目录。

## 日常使用

- “立即同步”：执行一次取数、检查和必要的屏幕更新。
- “强制重发”：忽略相同内容去重，重新发送当前完整画面。
- “暂停自动同步”：暂停期间不取数、不连接、不传图；恢复后补一次最新检查。托盘菜单即时生效；命令行或外部改写 `settings.json` 的暂停/换链接/改年度，后台会监测配置变化并及时重新读取，不必等待完整 30 分钟周期。
- “查看预览”：打开最近一次在本机生成的 800×480 画面。
- 默认每 1800 秒检查一次，启动后立即检查一次。

## 版式分档

- 1–5 项：宽松 v0.16。
- 6–12 项：标准 v0.11（结构沿用已批准 v0.6）；11–12 项使用标准容量子样式。
- 13–30 项：紧凑 v0.19。
- 超过 30 项或真实文本溢出：不发送删减版，保留上一张完整画面并报告 `LAYOUT_OVERFLOW`。

数量决定起始档位；用完整文本和最终字体测量后，如果起始档放不下，会按已批准的更密档位逐级实测回退。全部档位都放不下时才报 `LAYOUT_OVERFLOW`，保留上一张完整画面，不会截断事项，也不会发送未批准的小字号版式。

## 故障判断

- `未发现目标看板`：屏幕未上电、超出范围或未广播；PC 画面不会被改写。
- `蓝牙连接超时`：Windows 蓝牙链路卡死；在“设置 → 蓝牙”里关闭再开启蓝牙后重试，看板无需断电，屏幕保持原画面。
- `蓝牙被占用`：LCD 看板正在通过跨项目租约使用蓝牙；等待 LCD 恢复后重试，墨笺不会同时扫描或连接 EPD。
- `蓝牙传输失败`：连接、CRC、ACK 或刷新链路失败；屏幕保持原画面。
- WPS 读取失败：有上次成功画面时发送带红色失败页脚的缓存画面；没有缓存时显示云端读取失败页。
- 有效空表：显示“暂无待办”；读取失败不会被当成空表。
- 看板电压 `<=2800mV`：暂停自动传图并提示。
- 蓝牙每次连接预算 30 秒、最多重试 5 次（间隔 5/10/15/20 秒）。实测单次连接成功只需 7–14 秒，失败通常会挂到预算；失败后立刻重试往往即可成功。

## 与 Magpie LCD 共用蓝牙

如果本机同时运行 Magpie LCD Bridge 托盘控制器，墨笺会在 `scan`、`calibrate` 和真实传图期间申请本机 BLE 租约。LCD 会短暂暂停并可能回到时钟模式；墨笺完成或失败后释放租约，LCD 自动恢复。

- 内容未变化的检查和 `preview` 不申请租约。
- 全部 BLE 重试共享一个租约，正常操作约每 30 秒续期。
- 墨笺异常退出后，LCD 最长在租约 TTL（默认 120 秒）后自动恢复。
- LCD 控制器未运行时，墨笺记录协调不可用并保持原有独立运行能力。

2026-11-05 部署验收：连续 3 次 `calibrate` 均退出码 0，LCD 未出现非计划 BLE 超时；强制结束一次校准进程后，LCD 在约 120 秒 TTL 到期后自动恢复并完成发送。该结果证明进程/BLE 发送层恢复有效，不替代实体屏最终目视确认。

## 当前限制

- 目标 `NRF_EPD_F3FA` 可连接并已多次成功发送；标准 v0.11、宽松 v0.16 与紧凑 v0.19 均已获用户视觉/真机确认。
- 当前固件尚未稳定回报 `v=<mV>`；未取得电压时画面显示 `电量 --`，不会伪造百分比。
- 读取走 Playwright 自带 Chromium 配置目录与 WPS 网页 OpenAPI，不调用 WPS 桌面进程；2026-11-05 已在 WPS 桌面进程完全关闭时读取 9 项并成功上屏。
- 30 分钟后台检查已在打包版实测：上一轮 `12:03:18` 完成，下一轮 `12:33:18` 自动检查并读到 4 项；内容未变化时不连接看板。
- 三色方向与红黑极性已由校准图目视确认；实际观看距离、30 项物理可读性仍待真机确认。
- 预览文件位于 `%LOCALAPPDATA%\InkMemo\previews\`，可能包含真实事项，不能提交或外发。
- 看板年度是手动配置（`set-year`）。跨年后若仍是旧年度，`3.18` 这类无年份日期会被解析成上一年并整体判为逾期；目前不做自动推年，需在元旦后手动更新。
- 实测容量（全角汉字连续排布）：12 项标准版在事项 ≤20 字时可完整落屏，22 字起横向溢出并回退紧凑版。30 项以上或两档都放不下时返回 `LAYOUT_OVERFLOW`，屏幕保持上一张画面并弹出“版面放不下”提示；不会截断文字。
